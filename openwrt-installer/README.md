# OpenWrt Passthrough Installer for Proxmox VE

Скрипт для развёртывания OpenWrt в Proxmox VE с проброса физических сетевых
портов (PCI Passthrough) напрямую в виртуальную машину — для роутера с
минимальными задержками и накладными расходами на CPU.

## Что делает скрипт

- **IOMMU / VFIO.** Определяет CPU (Intel/AMD), прописывает нужный флаг в
  `/etc/kernel/cmdline` (systemd-boot) или `/etc/default/grub`, включает
  модули `vfio*` и предлагает перезагрузку.
- **Установка OpenWrt.** Находит последнюю стабильную версию на
  `downloads.openwrt.org`, скачивает образ x86_64 (с таймаутами и
  повторными попытками), проверяет SHA256, создаёт VM (VMID и storage
  проверяются на валидность/занятость, ядра/RAM/диск — на то, что введено
  число), настраивает EFI-диск, импортирует и расширяет диск.
- **Мост + NIC (опционально).** Подбирает свободное имя `vmbrN`, создаёт
  Linux Bridge в `/etc/network/interfaces`, подключает к VM VirtIO NIC.
- **Статус.** Отдельным пунктом меню можно проверить, активен ли IOMMU и
  какие модули VFIO загружены, не запуская настройку заново.
- **IOMMU-группы.** Показывает разбивку PCI-устройств по IOMMU-группам и
  помечает, какие из них можно пробрасывать по отдельности (группа из
  одного устройства), а какие — рискованно (устройство делит группу с
  другими). Сам passthrough скрипт не делает — только даёт картину для
  планирования, когда он понадобится.

Проброс конкретного PCI-устройства (сетевой карты) в веб-интерфейсе Proxmox
скрипт не делает — PCI-адреса уникальны для каждого сервера, это нужно
сделать руками один раз, шаги ниже.

## Запуск

```bash
wget -qO openwrt-pve-installer.sh https://raw.githubusercontent.com/Mishazx/proxmox-scripts/main/openwrt-installer/openwrt-pve-installer.sh && bash openwrt-pve-installer.sh
```

Запуск через `curl | bash` не поддерживается — скрипту нужен физический
файл на диске (в частности, чтобы потом предложить его удалить).

## После установки: проброс PCI-устройства

1. Web-интерфейс Proxmox → созданная VM → вкладка **Hardware**.
2. `Add` → `PCI Device` → режим **Raw Device** → выбрать сетевой контроллер.
3. Включить **All Functions** и **ROM-Bar**.
4. Запустить VM: `qm start <VMID>`.

## Требования

- Proxmox VE 7.x/8.x.
- В BIOS включена виртуализация с IOMMU (Intel VT-d / AMD-Vi).
- Минимум 512 МБ свободного места на storage для образа/диска VM.
